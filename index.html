Telegram Web Bot SDK

Docs

Introduction

The Telegram Web Bot SDK allows you to embed a bot directly into your website. It mimics real Telegram bot functionality while giving developers easy integration.

Installation

Include the SDK in your HTML:

<link rel="stylesheet" href="https://your-app.onrender.com/sdk.css">
<script src="https://your-app.onrender.com/sdk.js"></script>

Basic Usage

Initialize the SDK after including it:

TelegramBot.init({
  botId: "1234567890",
  theme: "dark"
});

API Methods

Example of sending a message:

Api.sendMessage({
  text: "Hello world!",
  reply_markup: {
    inline_keyboard: [
      [{ text: "Home", callback_data: "/home" }]
    ]
  }
});
